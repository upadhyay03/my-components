# React Component Development Assignment

This project was built as part of a **Front-End React Assignment**.  
It includes two reusable UI components implemented with **React, TypeScript, TailwindCSS, and Storybook**.

---

## 🚀 Tech Stack
- React + Vite + TypeScript
- TailwindCSS (styling)
- Storybook (documentation & preview)
- Vitest (basic testing, via Storybook setup)

---

## 🎯 Components

### 1. InputField
A flexible input component with multiple states and variants.

**Features:**
- Label, placeholder, helper text, error message
- States: disabled, invalid, loading
- Variants: `filled`, `outlined`, `ghost`
- Sizes: `sm`, `md`, `lg`
- Responsive + accessible (ARIA labels)

---

### 2. DataTable
A table component to display tabular data with basic functionality.

**Features:**
- Display tabular data
- Column sorting
- Row selection (single/multiple)
- Loading state
- Empty state
- Responsive + accessible
